# Проверка MVP

Проверено 23 сентября 2026 года в локальном проекте.

- TypeScript: `npm run typecheck` — успешно.
- ESLint: `npm run lint` — успешно, без ошибок и предупреждений.
- Автотесты: `npm test` — 5 тестов успешно. Использована отдельная временная SQLite-база.
- Production: `npm run build` — успешно; приложение запущено через `npm start` на http://127.0.0.1:3000.
- Браузер: пройден путь «Вставить пример → Уточнить с AI → три вопроса → карточка → подтверждение 20 → дополнение 60 → дополнение 100 → публикация → предложение команды → выбор бизнеса → отправка результата → подтверждение этапа».
- Браузер: проверены фильтр «Черновик» (две исходные задачи), пустой поиск и сброс фильтров. В проверенной production-вкладке ошибки консоли не зарегистрированы.
- Перезапуск: сервер разработки остановлен, запущен новый production-процесс. Новая задача осталась опубликованной с рейтингом 100, отклик — selected, этап — confirmed, баланс Data Qadam — 50.
- Повторное подтверждение этапа после перезапуска вернуло `alreadyConfirmed: true`, без дополнительного начисления.

В рабочей базе сохранён пройденный демонстрационный сценарий: задача `cmudxmv4m0001uefgqf5a83w6`. Поэтому в текущем каталоге шесть задач: пять исходных и одна созданная во время проверки. Чистый запуск seed из архива создаст только пять исходных.

Реальный AI-провайдер не настроен и live-вызов не проверялся. Интерфейс явно показывает AI: demo. Проверка JSON-контракта, неизвестных полей и ссылок на источники покрыта тестом; реальные качество ответов и совместимость конкретного провайдера требуют его подключения.

Проверка дизайна выполнена в desktop-браузере. Дополнительная мобильная CSS-компоновка предусмотрена, полноценная мобильная проверка не проводилась.
