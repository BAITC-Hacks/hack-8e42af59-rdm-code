# Проверка обновления — 23 сентября 2026

## Backend и AI: повторная проверка 23 сентября 2026

- `npm run typecheck`, `npm run lint`, `npm run build` — успешно.
- `npm test` — 18 тестов, все прошли, в отдельной временной SQLite-базе.
- Проверены реальные SQL-транзакции: несколько одновременных одинаковых предложений дают одну запись;
  четыре одновременных подтверждения этапа дают одну награду и ровно 50 баллов.
- Проверены приватность черновиков, неверные ID/роль, ссылки, неизменность API форматов,
  низкий рейтинг, несколько выбранных команд и повторное подтверждение после изменения карточки.
- AI: проверены строгий JSON Schema запрос OpenAI Responses и прежний Chat Completions адаптер
  с подменой HTTP-ответов. Проверены 401, 429, 503, timeout, сетевой сбой, refusal, неверный/слишком большой
  ответ, повторяющиеся вопросы и неверные источники. Во всех этих случаях есть явный deterministic fallback.
- `npm run test:http` — успешно против отдельного production-сервера на 3107 и временной базы:
  сессионная авторизация, доступ к AI только бизнесу, mock вопросы/карточка, сохранение текста/ответов,
  GET /api/drafts, публикация, приватный отклик, выбор команды, подтверждение этапа, редактирование
  и повторная публикация, отзыв сессии. Перезапуск этого сервера сохранил задачи и 50 баллов в базе.
- В рабочую базу применена добавочная миграция `20260923170000_backend_reliability`, без reset/drop.
  До миграции сделана локальная резервная копия. Seed добавил отсутствующие исходные карточки,
  сохранив прежние записи; HTTP-тесты рабочую базу не использовали.

**Реальный OpenAI-запрос пока не выполнен:** при проверке настройки OPENAI_API_KEY и AI_API_KEY были пусты.
Согласие на один небольшой запрос получено, но действительность ключа, доступ модели и $50 кредита
не подтверждены. После локального ввода ключа: AI_MODE=live, AI_PROVIDER=openai,
`npm run ai:check -- --live` (не более одного запроса). Mock-тесты не доказывают работу реального провайдера.

UI-файлы не менялись, новая визуальная проверка не проводилась. Возобновление незаконченной формы
из GET /api/drafts и отдельный Vite Frontend остаются задачами frontend-команды:
[точный контракт и ограничения](./docs/BACKEND_CONTRACT.md).
